# Реализация проекта

Разработано приложение — REST-сервис облачного файлового хранилища.

Приложение предоставляет возможность:

* загружать файлы;
* получать список файлов пользователя;
* скачивать файлы;
* переименовывать файлы;
* удалять файлы.

Frontend приложение располагается в папке [FRONT](front).

Frontend взаимодействует с Backend через REST API.

---

# Реализованный функционал

Сервис реализует следующие функции:

# Авторизация и безопасность

После ввода логина и пароля приложение проверяет пользователя на наличие в базе данных.

Пароль пользователя хранится в зашифрованном виде.

В случае успешной авторизации:

* генерируется уникальный токен;
* токен сохраняется в базе данных;
* backend возвращает токен клиенту.

Полученный токен позволяет пользователю выполнять операции с файлами в течение срока действия токена.

После успешной авторизации все запросы от frontend отправляются с заголовком:

```text
auth-token
```

в котором передаётся токен пользователя.

Для последующих запросов backend выполняет проверку токена через:

```text
TokenAuthenticationFilter
```

Если токен валиден, пользователь получает доступ к следующим операциям:

* загрузка файлов;
* скачивание файлов;
* удаление файлов;
* переименование файлов;
* получение списка файлов.

При выполнении logout токен аннулируется (удаляется из базы данных), после чего пользователь перенаправляется на
страницу авторизации.

# Настройка CORS

Для корректного взаимодействия frontend и backend настроен механизм CORS (Cross-Origin Resource Sharing).

Backend разрешает запросы от frontend-приложения.

Настройка выполнена через:

```text
Spring WebMvcConfigurer
```

в классе:

```text
WebConfig.java
```

# Инструкция по запуску FRONT

## Необходимо:

1. Установить Node.js (версия не ниже 19.7.0):

https://nodejs.org/ru/download/

2. Скачать проект.

3. Frontend приложение располагается в папке [FRONT](front).

4. Все команды выполнять из папки FRONT.

5. В файле `.env` установить следующие настройки:

```env
PORT=8081
VUE_APP_BASE_URL=http://localhost:8080/cloud
```

6. Выполнить команды:

```bash
npm install
npm run serve
```

При необходимости можно выполнить production-сборку frontend:

```bash
npm run build
```
